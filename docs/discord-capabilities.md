## 미활성 기능 — 확장 후보 (★ = 비서 확장에 값어치 큼)

비서 시스템 확장 시 켜서 쓸 만한 것 우선 표시.

| 기능 (미활성) | 비서 활용 아이디어 |
|---------------|--------------------|
| ★ 이벤트 만들기 / 이벤트 관리 | 가족 일정 등록·리마인드 (병원 예약, 학교 행사) |
| ★ 투표 만들기 | 가족 의사결정 (저녁 메뉴, 주말 계획) |
| ★ 반응 추가 | 승인/확인 UX — 봇 제안에 ✅ 눌러 확정 |
| ★ 빗금 명령어 사용 (슬래시) | 구조화 명령 (`/알람`, `/식단`, `/지도`) — 현 `%`/`{{}}` 대체·보완 |
| ★ 공개/비공개 스레드 만들기 · 스레드 관리 | 주제별 대화 분리 (예나 식단 스레드, 가계부 스레드) |
| 웹후크 관리 | 외부 시스템 → 채널 알림 주입 (크론, CI, 센서) |
| 별명 변경 / 별명 관리 | 봇 표시명 상황별 전환 |
| 메시지 고정 | 중요 정보(주소, 반복 일정) 채널 상단 고정 |
| 메시지 기록 보기 | 과거 메시지 fetch — 컨텍스트 검색/요약 기능 시 |
| 외부 이모지/스티커 · 표현 만들기 · 사운드보드 | UX 꾸밈 (우선순위 낮음) |
| 음성: 연결 · 말하기 · 동영상 | TTS 알림, 음성 비서 (먼 미래) |
